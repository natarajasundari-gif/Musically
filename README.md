# Musically 🎵

Musically is a simple music-themed website created using **HTML and CSS**. It was built as a frontend practice project to explore webpage structure, styling, layouts, and navigation.

## Features

* Music-themed homepage
* Multiple webpages connected through navigation
* Styled layouts using CSS
* Responsive and visually appealing interface

## Technologies Used

* HTML5
* CSS

## How to Run

1. Download or clone this repository.
2. Open the main HTML file in a web browser.
3. Explore the different pages using the navigation links.

## Project Purpose

This project was created to practice the fundamentals of **HTML and CSS** and to understand how multiple webpages can work together as a single website.

## Note

This is a frontend practice project. It does not include a backend, database, or actual music streaming functionality.
